# Resist Force

Define this contract before calculations. Preserve Resist Force19308,
Force Powers18202 and Bonuses and Penalties16336. Standard activation,
self-target. UTF15/20/25 grants+1/+2/+3 to ONE chosen Defense against Force
Powers until the beginning of your next turn. The bonus is unnamed as printed;
reuse the general modifier resolver, including stacking unnamed contributions
from separate activated copies. It does not affect ordinary defenses, general
Use the Force uses or Dark Side/Light Side-independent non-power attacks.
Force-power Fortitude applies to Damage Threshold in that same context via
the existing defense-to-threshold resolver, not a global threshold increase.

Special FP applies the same bonus to TWO DISTINCT chosen Defenses. Choose
primary and optional additional Defense in the pointer form before rolling;
freeze a canonical selection with the original check so saved completion
cannot switch the initial choice. The second applies only if FP is paid;
ordinary check FP and Adept cannot also buy this special FP in the same round.
No invented bonus type, third Defense or fake attack penalty. Allow lower
earned tiers through the existing active-effect control until used.

Multiple instances are allowed. Maintain each instance separately with one
Swift Action on each new turn, with no new activation check. Damage while
maintaining requires a new UTF check at DC15+damage taken for EACH maintained
instance. Reuse Energy Resistance's saved pending-check/FP/keep/release and
atomic turn-reset machinery. Failed checks release only that instance;
incapacity, death/rest/encounter reset and source lifecycle use the same
maintenance cleanup as existing powers. Do not charge a new suite copy or FP
for maintenance. Unmaintained instances expire; pending checks block further
actions/resets until resolved or released. Natural1/20 is not automatic
success/failure on these skill checks and does not recover suite copies.

Extend the existing maintained resistance family with a defense variant,
sharing lifecycle validation, damage checks, action allocation, FP and UI.
Keep Energy Resistance DR/size/type/quickening and old saved shapes unchanged.
Use explicit conditional Force Powers rows, target context on incoming damage
and stat-block breakdown. The NPC's actual use/target remains external, so
Partial. New UI is terse and folded by default. Cache changed runtime/docs,
keep pinned text verbatim, test multiple copies/unnamed stacking, bonus
scope/threshold, choices/save/replay, both FP modes, real Adept/Mastery,
maintenance action substitutions/failure/rounds and old Energy Resistance.
Independent review and complete combined/UI/mobile/offline/hosted gates before
publication.
