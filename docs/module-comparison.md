# pmcrwf and wkolon modules

Compared 2026-10-24: pmcrwf’s published Pages site and wkolon’s current module registry. A counterpart does not imply identical game rules or complete automation.

| pmcrwf | wkolon | Notes |
| --- | --- | --- |
| Character | Character, Languages, Species Features | Identity is split across separate views. |
| Classes | Classes | XP is inside Classes. |
| Background | Destiny / Background | Choose Destiny, Background or neither. |
| Ability Scores | Ability Scores | Saga ability rules. |
| Saving Throws | Defenses | Reflex, Fortitude and Will are defenses. |
| Skills | Skills | Includes Initiative and Knowledge fields. |
| HP | HP, Damage Threshold | Includes SR, DR, bonus HP, damage and recovery. |
| Proficiency Bonus | Base Attack | BAB and half-level bonuses serve different roles from D&D proficiency. |
| Armor Class | Defenses | Reflex handles most ordinary weapon attacks. |
| Speed | Speed | Includes reviewed movement, Jump, falling and Acrobatics controls. |
| Initiative | Skills | Initiative is a skill; no separate module. |
| Counters | Force Points, Destiny Points, Dark Side Score | Specific resources exist; a general custom-counter module is absent. |
| Defenses | Defenses, HP | Typed defenses and some immunities exist; hazard resolution remains partial. |
| Senses | Senses | Existing vision and armor blindness, with automatic relevance and visibility controls. |
| Rest | HP, Condition Track | Recovery and rest controls are embedded. |
| Combat | Actions | Turn resources, immediate actions and queued plans. |
| Conditions | Condition Track, Defenses | Track, persistent conditions and some status controls; other conditions remain manual. |
| Exhaustion | Condition Track | Saga track rules, with the shared click-to-set style. |
| Death Saves | HP | Saga death and consciousness recovery; no D&D death-save counter. |
| Proficiencies | Skills, Feats, Languages | Distributed across the relevant views. |
| Attacks | Attacks | Reviewed weapon rolls, target declarations and modifiers. |
| Offensive Routines | Offensive Routines | Configurable offensive routines. |
| Inventory & Equipment | Inventory, Droid Systems | Owned gear, credits, quantities, weight and reviewed systems. |
| Companions & Summons | - | Companions/Followers module is missing. |
| Event Log | Event Log | Shared roll log and Tumble controls. |
| Features | Class Features, Species Features, Feats, Talents, Force Techniques, Force Secrets, Medical Secrets | Split feature modules, with Manual/Partial markers. |
| Inventory Tracker | Inventory, Event Log | A separate dated gains/spending ledger is missing. |
| House Rules | House Rules | User rulings, Ambiguities, optional rules and Jedi Counseling. |
| Spellcasting | Force Powers | Force suites, checks and reviewed effects; manual effects retain coverage markers. |

Additional wkolon views: Starship Maneuvers, Vehicles, Force Traditions, Modifiers, Notes.

The clearest module gaps are Companions/Followers, a general counter view and a dated inventory ledger. Other proposed splits remain in docs/modules-roadmap.md.
