# Force Track

Define this contract before calculations. Preserve Force Track20424, Force
Powers18202 and Combat Sequence26725 verbatim with attribution. Swift Action,
Self. UTF15/20/25/30 permits following the path of a designated creature that
passed through the area in the last1/10/60/1440minutes respectively. The caster
must have Line of Sight to the trail. The effect allows tracking that creature
without Survival checks for up to1hour. Below15 has no effect. The special FP
allows up to2 designated creatures simultaneously instead of1; it does not
extend duration, improve trail age or grant an unnamed Survival bonus.

Capture one required quarry name and one optional second name as canonical
trimmed, distinct, bounded strings at activation. Without special enhancement,
only the first quarry is active. The second is used only if enhancement is
chosen; paying for capacity2 does not require a second quarry. Freeze these
names before the saved check/FP choice. Preserve lesser achieved tiers and the
shared ordinary-versus-special FP, Adept/Mastery, suite copy and natural20
recovery rules. The earned-tier chooser describes Trail age, not damage.
No retroactive effect from older manual pending power results.

Store a closed timed-power row keyed by the activation ID, with the selected
tier, chosen quarry names and600rounds remaining. Reuse the existing10rounds
per minute game-time constant and advancement entry point. An actual new
tracked turn advances1round; the initial Start turn advances none. A minute
spent recovering the suite advances10rounds. An eight-hour rest expires it.
Pure turn previews advance only their cloned state. Ending combat, beginning
an encounter and suite recovery after natural20 do not by themselves represent
elapsed time and must not erase the effect. The existing New day command
explicitly advances24hours of game time, so it expires the effect. Merely
editing daily resources does not. Do not derive duration from the operating
system clock or assume midnight ends a one-hour effect. Allow editing remaining game minutes in0.1minute
increments, consistent with the existing saved timer controls. Expire at0.

An active quarry control can log following that quarry without making a
Survival check, rolling dice, spending an action slot or spending another FP.
It represents the check exemption, not instantaneous movement or free travel.
Other Survival applications still roll normally. Display the quarry, remaining
minutes and maximum trail age; actual trail visibility/age, path, obstacles,
tracking movement and finding the creature remain external, so Partial.
Trail age is the qualification when activating, not a countdown that cancels
the hour after one minute. Editing one saved timer does not advance other
timers. Removing the effect ends only that activation's tracking permission.

Test thresholds/lesser tier/FP target capacity, saved names/checks, expiry and
every time/reset path above, no-RNG follow/preview, normal Survival isolation,
genuine Adept/Mastery/recovery, legacy compatibility and unsupported trail
boundaries. Independent review, combined checks, actual controls/mobile/refused
offline and hosted gates precede publication.
