# Creation controls

Reading and selecting are separate operations. Triangles disclose the complete
pinned rules inline, including for unavailable records. Select/Selected controls
choose records; selecting never opens a rules popup. Prerequisite indicators
remain read-only. Imported wiki links retain their rule navigation.

Feat and talent secondary choices use a dedicated follow-up view with Back to
return to the primary library. Skills, weapons, powers and other named choices
use the same Select controls and inline rules. Manual declarations remain fields.
All rules start folded when opening a choice screen.

Unresolved choices link to their exact level and selection slot when available,
otherwise the relevant creation tab or field. Navigation must not change a build.

Point buy edits named abilities directly. Existing assigned pools retain their
scores; unused purchases fill remaining abilities in pool order. Other generation
methods retain assignment. Droid and organic ability profiles remain independent.
Species search ranks exact and partial name matches before full-text matches;
explicit column sorting overrides relevance until the query changes.

Graph routes retain the 60 degree limit before smoothing, proportional cubic
curves, aligned arrowheads and crossing underpasses. Redundant injected Force
Sensitivity edges are omitted when a mandatory prerequisite already implies it;
printed prerequisites and eligibility checks are unchanged.

Average credits is an explicit alternative to the initial class credit roll,
using the existing mean calculation and the same once-only assignment guard.
It does not turn on the average-credits house rule. When that rule is on, the
existing forced-average behavior remains in effect.

A character starting in Jedi receives the printed standard Lightsaber in their
inventory automatically, with the existing starting-grant provenance and no
credit deduction. The claim persists after removing it or changing classes;
multiclassing into Jedi grants no starting Lightsaber. It also applies when
creating higher-level characters whose first class is Jedi. Vehicles belongs
outside the starting-credit controls.
