# Character creation

Levels is the main view. Each row records a character level, its class, cumulative
Base Attack Bonus, Heroic Feats, Class Feats, Class Talents, Ability Score
Improvements and other class features. The level control plans characters from
1 to 20. Unchosen classes remain pending and grant no HP, BAB, trained skills,
feats, talents or Force Points. Existing saved class choices are preserved.

Selecting a class, feat or talent opens its prerequisite graph. The five base
classes appear first, above the prestige classes. Class availability uses only
earlier earned levels; changing an earlier choice preserves later selections
and flags choices whose prerequisites are no longer met.

Abilities, Species, Skills, Equipment and Character have separate tabs.
Generation and assignment share the Abilities view. New drafts begin with an
unassigned standard pool. Manual, point-buy and rolled pools save separately
from assignments; changing an assigned pool entry updates its ability score.

The Character tab records [Heroic Traits and story choices](heroic-traits.md).
Notes and additional Languages remain editable on the sheet. Feat and talent
pickers retain their own screens, full imported mechanics and secondary choices.
