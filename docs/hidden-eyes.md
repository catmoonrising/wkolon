# Hidden Eyes

This contract precedes calculations. Preserve Surveillance Talent Tree revision
20064, Hidden Eyes (Clone Wars Campaign Guide), actual Scout access and its
printed lack of additional prerequisites.

Hidden Eyes grants +5 circumstance on Perception checks against a target from
which the character has Concealment. Add one declared use to the shared skill
application registry: Against target (you have Concealment). The player declares
the target and Concealment through this selection. Use a named circumstance
identity, `hidden-eyes`, in shared typed bonus resolution.

Every Perception application against that target can qualify, so this use does
not invent a restriction to Notice Targets or Sense Deception. Existing reroll
conditions remain independent declarations and retain their application
intersection rules. Preserve native skill totals for unrelated actions, scoped
check totals, source loss and native-only replacement-skill boundaries. The
actual full source remains accessible through the talent. Mark Partial because
external targets and positions remain declared. Use a complete Scout fixture.
