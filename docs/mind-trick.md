# Mind Trick

Define this contract before calculations. Preserve Mind Trick24983 and Force
Powers18202. Reuse actions, Use the Force checks, normal/special FP choices,
Adept/Mastery, descriptors, suite recovery and saved original results. Keep
the catalog Partial: another creature's behavior, awareness, Dexterity bonus,
Attitude, movement and subsequent attacks are external to this sheet.

Standard Action, one creature with Intelligence3+ within12squares and Line of
Sight. These positional and target restrictions remain explicit source text;
optional declared Intelligence must reject a known ineligible target before
rolling. Never fabricate hidden NPC stats. An optional target Will permits
an exact success result; otherwise show the inclusive Will hit limit.

Choose one mode. A successful check (UTF >= Will) permits:
- Hallucination: target awareness does not prevent a Stealth attempt.
- Feint: the next attack against this target ignores its Dexterity bonus to
  Reflex (if any). Do not deny Dexterity against every opponent or mutate
  the caster's own Dexterity, Defenses or unrelated target flags.
- Suggestion: require confirmation that communication is possible and the
  suggestion does not obviously threaten the target's life. Its suitability
  remains GM judgment. The Jedi Counseling examples remain Manual rather
  than invented NPC decision logic or a mechanical override of the base rule.
- Fear: target flees at top speed for1minute, stopping if wounded. It is a
  Fear effect and fails against targets whose level >= caster Character
  Level. Snapshot Character Level (not class level or target level). If
  target level is unknown, state the eligibility limit without guessing.

Only a successful Suggestion has the special FP Attitude effect: improve by
1 + floor((UTF - Will)/5) steps. If Will is declared, compute the exact number;
if hidden, display the formula and hit limit. Do not invent an Attitude, call
Friendly an ally, make the target harm itself, or treat this UTF power as a
Persuasion check for Master Manipulator. Other Mind-Affecting/Fear immunities
remain external target checks. A failed check never produces a negative
Attitude improvement. Ordinary check FP and special FP obey the shared ledger.

Keep target declarations and chosen mode in a closed original snapshot. Queue
and preview spend nothing. Save/reload preserves the roll and waits for the
final FP choice without another check or duplicate resource use. A check FP
may turn a known miss into success; a successful Suggestion may instead use
the special FP. Non-Suggestion modes must not offer an invented enhancement.
Older manual pending results remain manual, without retroactive NPC effects.

Use the same pointer form, terse labels, default folded details and theme
controls as other powers. Show an Action selector only for powers with more
than one available action; their normal cost remains visible in the footer. Show known misses/immunities accurately, and keep
unknown outcomes conditional. Test target constraints, exact ties/margins,
fear level equality, mode-specific FP, real complete Adept/Mastery builds,
snapshots/legacy/replay, ordinary descriptor/DSS behavior and unchanged caster
stats. Independent review, combined regressions, real controls/mobile/offline
and exact hosted verification precede publication.
